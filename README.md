# Frank & Hongchen Wedding Website v4

Wedding date: 2027-02-21  
Venue: Hotel Nikko Kaohsiung, 3F Banquet Hall

## v4 重點更新

- Hero 首頁重新排版：文字移到天空留白區，避免遮住人物。
- 手機與桌機分別調整照片裁切與字級。
- 捲動後導覽列改為半透明毛玻璃固定導覽。
- 手機新增浮動 RSVP 快捷列；到 RSVP 區塊時自動隱藏。
- Countdown、日期卡、Venue、RSVP 視覺重新精修。
- Venue 新增「複製地址」。
- 新增 `frank-hongchen-wedding.ics`，賓客可把婚宴加入行事曆。
- RSVP 以 01 / 02 / 03 分段，出席者欄位條件式展開。
- Email、出席人數、飲食需求仍只在「會出席」時必填。
- 不新增其他生活照片，網站仍只使用 `hero.webp`。

## GitHub 更新方式

將以下 6 個檔案上傳到 repository 根目錄，選擇覆蓋同名檔案：

- `index.html`
- `styles.css`
- `script.js`
- `hero.webp`
- `frank-hongchen-wedding.ics`
- `README.md`

Repository 根目錄應為：

```text
frank-hongchen-wedding/
├── index.html
├── styles.css
├── script.js
├── hero.webp
├── frank-hongchen-wedding.ics
└── README.md
```

GitHub Pages 保持：Settings → Pages → Deploy from a branch → `main` → `/ (root)`。
